# Ben Eater 6502 Emulator

A planned JavaFX desktop emulator of the extended Ben Eater breadboard computer. The default machine includes a W65C02S CPU, W65C22S VIA, HD44780-compatible 16×2 LCD, and W65C51-family ACIA. The project targets cycle-accurate observable digital behavior, headless testing, and native desktop distribution.

Phase 1 is planning. Start with the [architecture](docs/architecture.md), [hardware reference](docs/hardware.md), [test strategy](docs/testing.md), and [backlog](docs/backlog.md). See [contributing](CONTRIBUTING.md) for the GitHub Copilot workflow.
