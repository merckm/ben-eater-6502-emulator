# ADR 0002 — Cycle and device time

**Accepted direction.** Use deterministic bus-cycle execution with explicit simulated timestamps and digital signals. Host pacing limits execution speed while devices use simulated clock deadlines. A headless trace validates cycle behavior independently of the JavaFX refresh rate. The machine thread serializes mutation, and inspection uses immutable snapshots or explicit peek methods. See [cycle contract](../architecture.md#cycle-contract).
